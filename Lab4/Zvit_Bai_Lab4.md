## Теоретичні відомості

### Концепція чистих функцій

* **Чиста функція** (*pure functions*) — це функція, яка для одного й того самого набору вхідних аргументів завжди повертає один і той самий результат. Вона не змінює
значення глобальних змінних, не модифікує передані їй аргументи, не виводить нічого на екран і не записує у файли, тобто не викликає жодних побічних ефектів (Side Effects).
* **Нечиста функція** може залежати від зовнішнього стану або змінювати його, що ускладнює тестування та паралельне виконання коду.

### Незмінність даних (Immutability)
— концепція, яка передбачає, що об'єкти після свого створення не можуть бути змінені. Замість модифікації наявного списку чи словника, функціональний підхід створює нові копії даних із внесеними змінами. Це запобігає непередбачуваним помилкам, пов'язаним із розділенням пам'яті (shared state).

### Функції вищого порядку
* `map(func, iterable)` — застосовує функцію до кожного елемента послідовності, трансформуючи його.
* `filter(func, iterable)` — відбирає елементи послідовності, для яких функція-умова повертає True.
* `reduce(func, iterable[, initial])` — послідовно згортає елементи колекції до одного єдиного значення, використовуючи акумулятор.

### Декоратори (Decorators)
Декоратор — це функція вищого порядку, яка приймає іншу функцію як аргумент, додає до неї певну нову поведінку (наприклад, логування, вимірювання часу, валідацію) та повертає модифіковану функцію, не змінюючи при цьому її початковий початковий код.

### Замикання (Closures)
Замикання — це функція, яка має доступ до змінних із зовнішньої функції навіть після завершення її виконання. Завдяки цьому замикання може зберігати стан між викликами без використання глобальних змінних.

### 1.4. Вихідний код програми (`BaiV_Lab4_Task1.py`)

```python
# task1_pipeline.py
from functools import reduce
from pprint import pprint

def main():
    # 1. Формування початкових даних (мінімум 5 записів)
    data = [
        {'Товар': 'Ноутбук', 'Кількість': 5, 'Ціна': 25000},
        {'Товар': 'Мишка', 'Кількість': 15, 'Ціна': 500},
        {'Товар': 'Клавіатура', 'Кількість': 12, 'Ціна': 1200},
        {'Товар': 'Монітор', 'Кількість': 8, 'Ціна': 7000},
        {'Товар': 'Навушники', 'Кількість': 20, 'Ціна': 1500},
    ]

    print("Початкові дані:")
    pprint(data)

    # 2. Фільтрація даних (Кількість > 10)
    filtered_data = list(
        filter(lambda x: x['Кількість'] > 10, data)
    )
    print("\nВідфільтровані дані (Кількість > 10):")
    pprint(filtered_data)

    # 3. Трансформація даних (Вартість партії = Кількість * Ціна)
    mapped_data = list(
        map(
            lambda x: {
                'Товар': x['Товар'],
                'Вартість партії': x['Кількість'] * x['Ціна']
            },
            filtered_data
        )
    )
    print("\nРозрахована вартість партій:")
    pprint(mapped_data)

    # 4. Агрегація даних (загальна сума)
    result = reduce(
        lambda acc, x: acc + x['Вартість партії'],
        mapped_data,
        0
    )
    print(f"\nЗагальна сума вартості всіх великих партій: {result} грн")


if __name__ == "__main__":
    main()
```

**Замикання**: Створити функцію-фабрику, яка використовує механізм замикання для збереження стану між викликами (наприклад, генератор унікальних ідентифікаторів або лічильник викликів з певним кроком).

### 2.2. Вихідний код програми (`BaiV_Lab4_Task2.py`)

```python
# task2_decorators.py
import time

# --- Частина 1: Декоратор ---

def execution_logger(func):
    """Декоратор, що логує ім'я функції, її аргументи та час виконання."""

    def wrapper(*args, **kwargs):
        # Фіксація часу початку
        start_time = time.time()

        print(f"[LOG] Виклик функції '{func.__name__}' "
              f"з аргументами: args={args}, kwargs={kwargs}")

        # Виклик оригінальної функції
        result = func(*args, **kwargs)

        # Час завершення
        end_time = time.time()

        print(f"Функція завершила роботу. "
              f"Час виконання: {end_time - start_time:.4f} сек.")

        return result

    return wrapper

@execution_logger
def complex_calculation(x, y, delay=1):
    """Тестова функція для перевірки декоратора"""
    time.sleep(delay)  # Імітація довгої роботи
    return (x ** y) + sum(range(10000))


# --- Частина 2: Замикання (Closure) ---

def make_config_multiplier(base_rate):
    """Функція-фабрика, що демонструє замикання."""

    def multiplier(value):
        return value * base_rate

    return multiplier

def main():
    print("=== Тестування Декоратора ===")

    # Виклик функції з декоратором
    res1 = complex_calculation(2, 10, delay=0.5)
    print(f"Результат обчислення: {res1}\n")
    print("=== Тестування Замикання ===")

    # Створення функцій на основі замикання
    tax_calculator = make_config_multiplier(1.30)
    discount_calculator = make_config_multiplier(0.95)

    # Тестові значення
    value = 1000

    print(f"Початкове значення: {value}")
    print(f"Tax calculation: {tax_calculator(value)}")
    print(f"Discount calculation: {discount_calculator(value)}")


if __name__ == "__main__":
    main()
```
